# Grumpy Gamer: Final Presentation

---

## Project Overview
- **Grumpy Gamer** is a multi-game platform featuring classic and RL-powered games.
- Supports single-player, multiplayer, and AI agent competition.
- Designed for extensibility and research in reinforcement learning.

---

## Tech Stack
- **Backend:** Python (FastAPI), Docker, JWT Auth
- **Frontend:** React, TypeScript, Playwright (E2E tests)
- **RL Agents:** Custom Python agents, Gym environments
- **Deployment:** Vercel (frontend), Docker Compose, Fly.io

---

## Key Features
- Play classic games: Sudoku, Wordle, Chess, Checkers, Connect Four, Othello, Minesweeper, 2048
- Compete against RL agents or other players
- User authentication and stats tracking
- Replay and analyze games
- Extensible agent and environment framework

---

## Challenges
- Integrating RL agents with real-time multiplayer
- Ensuring fair play and security
- Managing state and performance for multiple games
- Cross-platform deployment and CI/CD
